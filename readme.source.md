## Tecnologias exibidas

As tecnologias apresentadas no topo do perfil são controladas manualmente.

Atualmente:

- HTML
- CSS
- JavaScript
- React
- Java

Isso é proposital.

A atividade do GitHub pode ser automatizada, mas o perfil profissional não deve simplesmente assumir que uma linguagem usada em um exercício significa que você domina aquela tecnologia.

## Dados atualizados automaticamente

O sistema atualiza:

- Stars
- Forks
- Quantidade de repositórios públicos
- Commits
- Linguagens utilizadas nos repositórios
- Distribuição das linguagens
- Calendário de contribuições
- Total de contribuições
- Informações dos projetos destacados

## Projetos destacados
